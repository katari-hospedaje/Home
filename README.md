
# Apart Hotel Kunturi 🦅
### Sitio web oficial — Arica, Chile

Landing page del Apart Hotel Kunturi, un apart hotel boutique ubicado en Arica, el norte de Chile. Departamentos independientes con espíritu humano y diseño retro-moderno.

## Secciones de la página

1. **Navbar** — Logo + navegación fija + botón de reserva
2. **Hero** — Tagline principal + CTA
3. **Sobre nosotros** — Historia y personalidad del hotel
4. **Apartamentos** — 3 tipos de alojamiento con precios
5. **Servicios** — 8 servicios con íconos
6. **Ubicación** — Mapa + información de contacto
7. **Galería** — 6 imágenes en grid
8. **Testimonios** — 3 reseñas de huéspedes
9. **Contacto / Reservas** — Formulario + canales de contacto
10. **Footer** — Links + redes sociales + créditos

---

## Publicación con GitHub Pages

1. Ir a **Settings** del repositorio en GitHub
2. Sección **Pages** → Source: `Deploy from a branch`
3. Branch: `main` / Folder: `/ (root)`
4. Guardar — en unos minutos la web está en:
   `https://katari-hospedaje.github.io/Home/`

---

## Cómo agregar imágenes

Subir las fotos a `assets/img/` y en el `index.html` reemplazar los placeholders según las instrucciones en los comentarios `<!-- IMAGEN: -->`.
